CETFind data methodology and provenance

How CETFind processes Maharashtra CET CAP source material into public historical cutoff and seat-matrix data, including validation and publication safeguards.

CETFind is built around a simple principle: public college information should be traceable to published source material and should not be presented as a guaranteed prediction.

Source and provenance

The project uses Maharashtra State CET Cell CAP publications as a source for supported historical records. The official CET Cell remains the authoritative source for current admission notices and rules.

Processing workflow

  1. Collect: source documents are gathered for supported course/year datasets.
  2. Extract: relevant cutoff and seat information is converted into structured records.
  3. Validate: records are checked and problematic imports can be held for review.
  4. Approve: records intended for public use pass the project's publication workflow.
  5. Publish: the public search and data-backed landing pages expose only the published dataset.

Why the pages use historical language

The site avoids presenting historical cutoff records as current guarantees. Academic years, CAP rules, seat availability and candidate pools can change, so the wording deliberately distinguishes historical evidence from current admission information.

Current coverage is limited

The public landing-page directory currently focuses on BBA records from the verified public dataset. New course/year coverage should be published only after the corresponding data has actually passed the project's publication workflow.
